# Evaluation report — Financial Fraud Detection Engine

Generated by `python -m app.cli evaluate`. **All data is synthetic** (`app/ml/synthetic.py`); these numbers
measure how learnable the simulator's fraud patterns are, not real-world performance.

## Data

- Simulation: 2000 customers, 923,247 transactions, 2,941 fraudulent (0.3%), seed 42
- Fraud by scenario: cnp_stolen 938, card_testing 828, cloned_card 572, device_compromise 359, account_takeover 244
- Deployment date D = 2026-08-01. Train: before D−60 days (528,521 rows); calibration: D−60…D−30 (75,172); test: after D (244,190, 999 fraud)
- Labels known at D for the training window: 1210 of 1505 true frauds (the rest were never reported or reported later); 37 wrongly disputed legitimate transactions are labelled fraud.
- Test labels are the simulator's **full ground truth**, including fraud that was never reported.
